# 민원업무 지식센터

법령정보센터형 업무매뉴얼 열람 화면과 FastAPI 기반 문서 관리 API입니다. 담당자가 HWP·HWPX·PDF·DOCX를 등록하면 파일 구조와 본문 전체를 검사하고, 개인정보 패턴이 없을 때만 새 문서 또는 개정 버전으로 저장합니다.

## 주요 기능

- 12개 업무분류 탐색, 본문 통합검색, 자동 목차
- 담당부서·현재 버전·개정이력·원문 다운로드
- 원본 PDF의 표·테두리 글상자·강조색을 그대로 보여주는 업무별 원문 서식 탭
- 문서를 덮어쓰지 않는 버전 관리
- HWP 5.x, HWPX, PDF, DOCX 본문 추출
- 확장자와 실제 파일 시그니처 교차 검증
- 암호화, 매크로·스크립트, 내장 객체, ZIP 폭탄과 경로 조작 차단
- 주민·외국인등록번호, 전화번호, 이메일, 면허·여권·계좌·카드번호 패턴 탐지
- 개인정보 탐지 시 파일 전체 차단 및 기존 자료 보존
- 탐지된 실제 값은 남기지 않는 업로드 감사기록
- SQLite FTS 검색 인덱스와 원자적 현재 버전 교체

## 실행

Python 3.11 이상에서 실행합니다.

Windows에서는 `start-server.bat`을 더블클릭하면 가상환경 생성, 패키지 설치, 서버 실행, 브라우저 열기를 한 번에 진행합니다. 관리자 키는 `.env`의 `ADMIN_KEY` 값을 사용하며, 없으면 실행 시 입력받습니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:ADMIN_KEY="32자-이상의-무작위-관리자-키"
uvicorn app.main:app --reload
```

- 열람 화면: `http://127.0.0.1:8000`
- 자료 등록: `http://127.0.0.1:8000/admin`
- API 문서: `http://127.0.0.1:8000/docs`
- 상태 확인: `http://127.0.0.1:8000/health`

제공된 통합민원 PDF는 기본적으로 `data/source-manual.pdf`에서 읽습니다. 다른 위치를 사용할 때는 `SOURCE_MANUAL_PATH`에 PDF 절대경로를 지정하세요. 예시자료를 열면 각 업무의 해당 페이지가 `원문 서식` 탭에 바로 표시됩니다.

브라우저 화면만 확인할 때는 서버 실행 후 `preview.bat`을 실행합니다.

## 업로드 API

```powershell
curl.exe -X POST "http://127.0.0.1:8000/api/admin/documents" `
  -H "X-Admin-Key: 32자-이상의-무작위-관리자-키" `
  -F "admin_name=담당자" `
  -F "title=주민등록 업무매뉴얼" `
  -F "category=주민등록시스템" `
  -F "department=마을자치과" `
  -F "summary=주민등록 민원 처리 절차" `
  -F "file=@통합민원업무매뉴얼.pdf"
```

기존 문서의 새 버전은 `existing_document_id`와 `change_note`를 함께 전송합니다. API가 받는 메타데이터는 제목, 업무분류, 담당부서, 요약, 개정사유, 기존 문서 ID, 담당자명으로 제한되어 별도 개인정보 컬럼을 저장하지 않습니다.

## 검사 정책

1. 파일명은 경로를 제거한 이름만 사용합니다.
2. 허용 확장자와 파일 내부 시그니처가 일치해야 합니다.
3. 압축 문서는 파일 수, 해제 크기, 압축률과 안전한 경로를 검사합니다.
4. 암호화 문서, 매크로·스크립트, 내장 객체는 차단합니다.
5. 일반 문서 등록은 모든 추출 구역에서 지원하는 개인정보 패턴을 검사합니다.
6. 일반 문서 등록에서 텍스트가 없는 PDF 페이지와 이미지 포함 문서는 검사 완료로 간주하지 않고 차단합니다.
7. 검사를 통과한 뒤에만 무작위 서버 파일명으로 원문을 저장하고 DB 트랜잭션을 완료합니다.

업무편람 첨부는 이미지와 개인정보 패턴이 포함된 HWP·HWPX·PDF·DOCX도 등록할 수 있습니다. 이미지 전용 PDF처럼 텍스트를 추출할 수 없는 페이지도 허용하며, 탐지 유형은 실제 값을 저장하지 않고 감사기록에만 남습니다. PDF의 일반 링크, 페이지 이동, 문서 열기 위치 지정처럼 구조가 복잡한 이동 동작과 판독이 어려운 주석·양식 필드는 허용하지만 JavaScript, 외부 프로그램 실행, 내장 파일 등 위험한 동작은 계속 차단합니다.

이미지 안의 글자는 OCR 검사 대상이 아니므로 업무편람 등록 담당자가 이미지에 개인정보가 없는지 확인해야 합니다. 이미지 내부까지 자동 검사하려면 별도 격리 OCR 워커, 한국어 OCR 언어팩과 OCR 누락 품질검증 절차가 필요합니다.

```powershell
pip install -r requirements-dev.txt

```

## 운영 전 필수 사항

- 관리자 화면을 기관 SSO 또는 VPN 뒤에 두고 `ADMIN_KEY`만으로 운영하지 마세요.
- HTTPS 역방향 프록시를 사용하고 업로드 저장소를 웹 루트 밖에 유지하세요.
- `DATA_DIR`의 DB와 원문을 함께 백업하고 서버 계정 외 접근을 제한하세요.
- 악성코드 백신 또는 CDR을 별도 파이프라인에 추가하세요. 본문의 개인정보 검사는 악성코드 검사를 대체하지 않습니다.
- 개인정보 패턴은 정책 담당자와 오탐·미탐 기준을 정기 검토하세요.
- 다중 인스턴스 운영 시 SQLite를 PostgreSQL로, 로컬 파일 저장을 기관 오브젝트 스토리지로 교체하세요.
